结论
找到一条此前未列出的官方元数据线索：美国站同一 Classic 商品的 newColorsBadging 数组包含 77631。但未找到澳洲站目标颜色的实际颜色变体、SKU、库存记录、真实 Classic 图片、有效购买链接或可证实的上架日期。

4. 官方图片服务
只测试三个已由官方确认的 Classic 款号 LW3LH6S、LW3LHPS、LW3LYAS，没有枚举未知款号或组合色号。
六个资产：三个款号分别拼接 _077631_1、_077631_2。
例：GET https://images.lululemon.com/is/image/lululemon/LW3LYAS_077631_1?req=exists
六个请求均 HTTP 200，正文 catalogRecord.exists=0。
三张 _1 的 ?req=props 均 HTTP 403，正文 Unable to find image。此处是图片服务业务响应，区别于网页的 Akamai Access Denied。

图像二进制验证：对三个 Classic _077631_1 请求 ?wid=480&fmt=jpeg，均 HTTP 200、Content-Type=image/webp、54 字节、480×480。
三者 SHA-256 均为 f6d0bc85be06f7b3aead84613bc2c4b33be2b0e6e303686fed24cd09857f8f6e，与人为设置的不存在资产 codex_lulu_nonexistent_control_20261115 完全一致。
正常 Classic 正对照 LW3LH6S_075787_1：req=exists 为 1；渲染为 480×576、10,624 字节，哈希不同。
正常新增款号正对照 LW3LYAS_081758_1：req=exists 为 1，req=props 显示原始 1800×2160。
Oversized 正对照 LW3LH4S_077631_1：req=exists 为 1；渲染为 480×576、12,004 字节。不是目标。

6. 接口访问失败与不存在的边界
/api/graphql：澳美均 HTTP 400，Cannot query field "productDetailPage" on type "Query"。这是 schema 不匹配。
/cne/graphql：本次已在当前公开 PDP 脚本中核实其作为备用路径存在；不是主要启用的 REST 数据源。
对从脚本提取的 GetPdpDataById 查询，美国 HTTP 403 Access Denied。
澳洲 HTTP 200，但 errors 含 GQL_PCM_API_ERROR_400 / PCM_API_ERROR_400，data.productDetailPage=null；将 fetchPcmMedia、fetchVariants 改为脚本默认 false 后仍同样错误。不是 NOT_FOUND，不能解释为目标不存在。
基于香港已核实 SFCC 形式测试澳洲旧 Product-Variation 路由，目标与已知正常颜色对照均返回 HTTP 404 HTML。说明该旧路径未取得商品结果，不是 077631 特定不存在的证据。
